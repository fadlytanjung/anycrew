# ADR-001 — Canonical Markdown with portable front matter; native files generated per assistant

**Status:** Accepted · **Date:** 2026-10-29

## Context
Each assistant reads agents, skills, rules and hooks from different folders with different front
matter. Skills have a cross-tool spec (Agent Skills) and `AGENTS.md` is universal; subagents, rules
and hooks are not. We want one source of truth that is also installable without a build step.

## Options considered
| Option | Costs | Gives |
|---|---|---|
| Maintain native folders by hand for each assistant | drift, N× edits | nothing |
| Depend on ruler or rulesync to generate | an extra tool and its schema; our inputs are narrower | broad target coverage |
| Own canonical files + a small generator | ~600 lines of Node to maintain | repo doubles as Claude plugin and Agent Plugin; exact control of each output |

## Decision
Canonical files live at the repo root: `agents/*.md` (front matter with portable `tier` and a Claude
`model` alias kept consistent by validation), `skills/*/SKILL.md` (spec fields only), `rules/*.md`
(Antigravity-style `trigger`/`globs`). The CLI generates each assistant's layout into a project and
marks every generated file so `sync` never overwrites hand-written files.

## Consequences
- Good: the repository installs directly as a Claude Code plugin, an Antigravity plugin and an Agent
  Plugin; projects get native files for six assistants from one command.
- Bad: canonical agents cannot carry a `model` (Antigravity's loader rejects non-tier values), so
  the Claude Code plugin is a generated plugin root at `plugins/claude/` (`npm run build:claude`,
  checked fresh by validation; Claude loads agents only from a plugin's own `agents/` folder) and Antigravity loads the canonical ones with `model: inherit`.
- Bad: rules inside a plugin install are always-on in Antigravity (plugin rules ignore `trigger`);
  the project layout generated by `init` honours triggers.

## How to revisit
If a cross-tool subagent standard appears, emit it as the universal layer and drop the per-tool agent
generators.
