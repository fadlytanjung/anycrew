# Decisions about anycrew

| ADR | Decision |
|---|---|
| [001](ADR-001-canonical-format-and-generation.md) | Canonical Markdown with portable front matter; native files generated per assistant |
| [002](ADR-002-semantic-model-tiers.md) | Agents declare `fast | balanced | strong`, mapped per assistant in `models.json` |
| [003](ADR-003-json-config-zero-dependencies.md) | JSON for configuration and presets; a zero-dependency Node CLI |
| [004](ADR-004-skills-prefix-and-spec-fields.md) | Skills are named `crew-*` and use Agent Skills spec fields only |
